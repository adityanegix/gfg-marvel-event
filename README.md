# DOOM PROTOCOL — GFG × Bennett University Tech Competition Landing Page
A responsive, cinematic event landing page for the DOOM PROTOCOL 72-hour tech/coding competition organized by the GeeksforGeeks Student Chapter at Bennett University.
Inspired by Marvel’s Doctor Doom aesthetic, it features interactive challenge tracks, role-based mission selection, expandable challenge briefs, a live Doomsday countdown, responsive navigation, accessible interactions, themed visuals, and mobile-friendly styling.
